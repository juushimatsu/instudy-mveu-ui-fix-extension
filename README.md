# InStudy Mono UI

Браузерное расширение, которое заменяет визуальное оформление учебного портала [disto.mveu.ru](https://disto.mveu.ru/) (InStudy) на тёмную монохромную тему с улучшенным UX.

> Портирование Tampermonkey-скрипта `main.js` v2.0.3 в нативное браузерное расширение без зависимости от Tampermonkey.

## Возможности

- **Тёмная монохромная тема** — полный CSS-оверрайд портала: фоны, текст, таблицы, кнопки, меню, шапка.
- **Переключатель темы** — тёмная ↔ светлая тема кнопкой в шапке.
- **Акцентные цвета** — 5 вариантов: mono, ocean, crimson, amber, forest.
- **Плотность интерфейса** — компактный, нормальный, широкий.
- **Боковое меню** — фиксированная узкая рейка (68px), раскрывается до 280px по hover.
- **Ранняя установка темы** — применяется до отрисовки страницы (document_start), нет «вспышки» белого фона.
- **Замена сломанных аватаров** — fallback с инициалами вместо broken img.
- **Погодные эффекты** — canvas-анимация дождя и снега (опционально).
- **Превью изображений в чате** — распаковка zip-архивов с изображениями и полноэкранный просмотр.
- **Выделение своих сообщений** — визуальное отличие сообщений текущего пользователя.
- **Кнопка «Наверх»** — появляется при прокрутке вниз.
- **🎮 Кликер «Студент»** — мини-игра прямо на странице портала! Доступна через пункт в боковом меню.

## Установка

### Google Chrome / Edge / Яндекс.Браузер (Manifest V3)

1. Откройте страницу управления расширениями:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите корневую папку этого проекта (ту, где лежит `manifest.json`).

### Mozilla Firefox (Manifest V2)

1. Переименуйте файл `manifest.firefox.json` в `manifest.json` (с заменой).
2. Откройте `about:debugging` → **«Этот Firefox»**.
3. Нажмите **«Загрузить временное дополнение»**.
4. Выберите файл `manifest.json` из корня проекта.

> **Примечание:** для постоянной установки в Firefox потребуется упаковать расширение через [addons.mozilla.org](https://addons.mozilla.org/).

## Использование

После установки откройте [disto.mveu.ru](https://disto.mveu.ru/). Тёмная тема применится автоматически.

### Кнопки в шапке (справа от аватара)

| Иконка | Действие |
|--------|----------|
| 🌙 / ☀️ | Переключить тему (тёмная / светлая) |
| 🌤️ / 🌧️ / ❄️ | Переключить погодный эффект (выкл / дождь / снег) |
| 🎨 | Выбрать акцентный цвет |
| ⊟ / ⊞ / ⊟⊟ | Переключить плотность интерфейса |

### 🎮 Кликер «Студент»

Мини-игра встроена прямо на страницу портала. Найдите пункт **«Кликер»** с иконкой 🎮 в боковом меню (слева) и кликните по нему.

**Механика:**
- Кликайте по книге 📚, чтобы зарабатывать «знания»
- Покупайте апгрейды (☕ Кофе, ⚡ Энергетик, 📝 Шпаргалка, 👤 Одногруппник, 👨‍🏫 Преподаватель, 🤖 ChatGPT, 🎓 Дипломная работа)
- Апгрейды дают пассивный доход знаний в секунду
- Прогресс сохраняется автоматически в `chrome.storage`
- При возвращении начисляется оффлайн-доход (до 4 часов)
- 10 уровней: от «Первокурсник» до «Ректор»

Игра открывается в модальном окне поверх страницы. Закрыть можно кнопкой ✕ или клавишей **Escape**.

### Popup-настройки

Нажмите на иконку расширения в панели инструментов браузера, чтобы открыть панель быстрых настроек.

## Настройки

Все настройки сохраняются в `localStorage` страницы disto.mveu.ru:

| Ключ | Значения |
|------|----------|
| `tm-theme` | `dark` / `light` |
| `tm-accent` | `mono` / `ocean` / `crimson` / `amber` / `forest` |
| `tm-density` | `compact` / `normal` / `wide` |
| `tm-weather` | `off` / `rain` / `snow` |
